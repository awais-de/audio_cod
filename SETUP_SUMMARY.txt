================================================================================
                              WHAT THE SETUP DOES
================================================================================

7-STEP AUTOMATED VERIFICATION:

✅ STEP 1: Virtual Environment
   - Creates venv/ directory if not exists
   - Isolates project dependencies
   - Provides activation commands for your OS

✅ STEP 2: Python Dependencies  
   - Installs all packages from requirements.txt
   - Upgrades pip first
   - Includes: PyTorch 2.10, Torchaudio, PESQ, STOI, etc.
   - Automatically handles version constraints

✅ STEP 3: FFmpeg Support
   - Checks if FFmpeg is system-installed
   - Provides OS-specific installation commands:
     * macOS: brew install ffmpeg
     * Linux: sudo apt-get install ffmpeg
     * Windows: choco install ffmpeg
   - Attempts to install Python codec packages

✅ STEP 4: Dataset Verification
   - Checks for datasets/LibriSpeech/train-clean-100/
   - Checks for datasets/LibriSpeech/test-clean/
   - Counts audio files in each
   - Provides download commands if missing

✅ STEP 5: Model Checkpoint Validation
   - Verifies Phase 1 Multi-scale Spectral checkpoint
   - Verifies Phase 2 Perceptual checkpoint
   - Verifies Phase 3 Extended Data checkpoint  
   - Verifies Phase 4 Adversarial checkpoint
   - Reports file sizes and locations

✅ STEP 6: Sanity Checks
   - Tests PyTorch import
   - Tests Torchaudio import
   - Tests NumPy, SciPy import
   - Tests PESQ/STOI metric libraries
   - Tests NeuralAudioCodec model loading
   - Detects available GPU (CUDA/MPS/CPU)

✅ STEP 7: Demo Scripts Verification
   - Confirms eval_testclean.py exists
   - Confirms eval_synthetic.py exists
   - Confirms demo_server.py exists
   - Confirms demo_client.py exists
   - Confirms ams_codec.py exists

================================================================================
                            TROUBLESHOOTING
================================================================================

ISSUE: "Failed to install dependencies"
FIX: Check internet connection, try: pip install -r requirements.txt

ISSUE: "FFmpeg not installed"
FIX: Install from: brew install ffmpeg (macOS) or apt-get (Linux)

ISSUE: "Models not found"
FIX: Check: find checkpoints_emergency -name "best.pt"

ISSUE: "Datasets not found"
FIX: Download from OpenSLR (see STEP 4 output)

ISSUE: "PyTorch import failed"
FIX: Activate venv, then: pip install --upgrade torch

ISSUE: "GPU not detected"
FIX: Check drivers, then: nvidia-smi (GPU should appear)
